# Inverse Optimization for Industrial Decisions

Research-oriented Industrial Engineering / Operations Research benchmark for **recovering latent objective preferences from observed optimization decisions**.

## Research question

When operational decisions are observed but the planner's objective coefficients are unknown, how accurately can inverse optimization recover those preferences and reproduce held-out decisions under new resource constraints?

## Current status

**Phase 1 implemented: forward LP oracle + constraint-generation inverse objective recovery + held-out decision-regret benchmark.**

The repository includes:

- a multi-product production/resource-allocation LP;
- seeded capacity scenarios;
- synthetic observed decisions generated by a hidden normalized profit vector;
- a forward LP oracle using HiGHS through SciPy;
- inverse objective recovery over the probability simplex;
- challenger/constraint generation from repeated forward solves;
- slack variables for inconsistent/noisy observations;
- uniform and random-objective baselines;
- held-out decision regret and objective-recovery diagnostics;
- tests and Python 3.10–3.12 CI.

## Forward problem

For product quantities `x >= 0`, resource matrix `A`, capacity vector `b` and latent profit weights `theta`:

```text
maximize  theta^T x
subject to A x <= b
           0 <= x <= u
```

The hidden objective is normalized:

```text
theta >= 0
sum_j theta_j = 1
```

Normalization removes the positive-scale ambiguity inherent in linear inverse optimization.

## Inverse problem

For each observed decision `x_i`, inverse feasibility requires it to be at least as good as every alternative feasible decision `y` under the recovered objective:

```text
theta^T x_i >= theta^T y - xi_i
```

with observation slack `xi_i >= 0`.

Enumerating every feasible `y` is unnecessary. The solver uses **constraint generation**:

1. solve the current inverse problem;
2. for each observation, solve the forward LP under the candidate `theta`;
3. if the candidate forward solution beats the observed decision beyond tolerance, add that challenger inequality;
4. repeat until no violated challenger remains or the iteration limit is reached.

The inverse master minimizes distance to a neutral prior plus observation slack.

## Evaluation

Primary metric: **held-out decision regret** under the true hidden objective.

Secondary metrics:

- recovered-objective cosine similarity;
- L1 objective error;
- number of constraint-generation iterations;
- number of challenger constraints;
- training consistency slack;
- held-out forward-decision agreement.

Objective coefficient recovery is not judged in isolation: different normalized objectives can induce similar decisions. Held-out decision quality is therefore the principal criterion.

## Scope boundary

This benchmark focuses on continuous linear resource-allocation decisions with unknown objective weights. Mixed-integer inverse optimization, unknown constraints, bilevel learning and preference drift are separate research extensions.
